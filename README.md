# เว็บไซต์โครงการจัดการเรียนการสอนตามหลักสูตรกระทรวงศึกษาธิการเป็นภาษาอังกฤษ (EP)
## โรงเรียนชลประทานวิทยา (Chonprathan Wittaya School)

ระบบเว็บไซต์ทางการและระบบบริหารจัดการข้อมูลหลังบ้าน (Admin Cockpit) สำหรับโครงการฯ ภาคภาษาอังกฤษ (English Program : EP) โรงเรียนชลประทานวิทยา

---

### 📌 1. เอกสารสรุปสำหรับประสานงานกับ "ศูนย์พัฒนาโรงเรียนดิจิทัล"

เมื่อนำโค้ดขึ้นเซิร์ฟเวอร์ของโรงเรียน ให้ส่งมอบและประสานงานกับศูนย์พัฒนาฯ ดังนี้:

#### 1.1 สิ่งที่โครงการ EP ขอรับการสนับสนุน:
1. **ขอเปิด Subdomain หรือโฟลเดอร์ Path:**
   - แบบแนะนำ: `https://ep.cpw.ac.th/` (Subdomain) หรือ `https://www.cpw.ac.th/ep/` (Sub-directory)
2. **ขอเปลี่ยนจุดหมายปลายทางของปุ่ม "English Program" บนหน้าหลักเว็บโรงเรียน (`cpw.ac.th`):**
   - เดิม: ชี้ตรงไปยัง Facebook Page (`https://www.facebook.com/profile.php?id=100093686707861`)
   - เปลี่ยนเป็น: ชี้มาที่ URL เว็บไซต์ EP นี้แทน (เช่น `https://ep.cpw.ac.th/` หรือ `https://www.cpw.ac.th/ep/`)
   - *ไม่ต้องกังวลเรื่องข้อมูลยังไม่พร้อม:* ระบบมีสวิตช์ **Visibility Gateway** ป้องกันไว้แล้ว คนทั่วไปที่คลิกมาจากเว็บโรงเรียนจะถูกส่งต่อไปยัง Facebook เพจเดิมอัตโนมัติทันที 100% จนกว่าทีมงาน EP จะกดเปิดสวิตช์ด้วยตนเอง
3. **การเข้าถึงสำหรับการอัปเดตโค้ด:**
   - ขอสิทธิ์ Git Access (`git pull`) ผ่าน SSH หรือสิทธิ์ SFTP/FTP/DirectAdmin ไปยังไดเรกทอรีเว็บไซต์

#### 1.2 ข้อกำหนดทางเทคนิคของเซิร์ฟเวอร์ (System Requirements):
- **Web Server:** Apache (พร้อม `mod_rewrite`) หรือ Nginx
- **PHP Version:** PHP 7.4 / 8.0 / 8.1 / 8.2+
- **PHP Extensions:** `json`, `session`, `mbstring`, `fileinfo` (มีเป็นค่ามาตรฐานอยู่แล้ว)
- **Database:** **ไม่จำเป็นต้องเปิดฐานข้อมูล MySQL/MariaDB เพิ่มเติม** ระบบใช้ Flat JSON Database ที่มีประสิทธิภาพสูง เบา ไม่กิน RAM เซิร์ฟเวอร์ และสำรองข้อมูลง่ายผ่าน Git
- **File Permissions:**
  - กำหนดสิทธิ์ให้ Web Server (www-data / apache) สามารถเขียนไฟล์ในโฟลเดอร์ `data/` ได้:
    ```bash
    chmod -R 775 data/
    chown -R www-data:www-data data/
    ```

### 🛡️ 2. กลไกสวิตช์ควบคุมการเผยแพร่ (Visibility & Facebook Gateway)

ระบบถูกออกแบบมาเพื่อแก้ปัญหา "อยากขอพื้นที่บนเซิร์ฟเวอร์แล้ว แต่ข้อมูลยังไม่สมบูรณ์ ไม่อยากให้บุคคลภายนอกเห็น":

1. **เมื่อเปิดโหมดปิดปรับปรุง (ค่าเริ่มต้น):**
   - **บุคคลภายนอก/ผู้ปกครอง:** เมื่อคลิกปุ่ม English Program จากหน้าเว็บโรงเรียน จะถูกส่งต่อไปยัง Facebook เพจ EP ทันที 100% โดยอัตโนมัติ (HTTP 302 Redirect) ไม่เห็นหน้าเว็บที่ยังเตรียมข้อมูลไม่เสร็จ
   - **แอดมินโครงการ EP:** เข้าสู่ระบบหลังบ้านได้ที่ `.../admin.php` เมื่อล็อกอินแล้ว จะสามารถเปิดดูหน้าเว็บจริงทุกหน้าเพื่อตรวจทานความถูกต้องได้ พร้อมมีแถบแจ้งเตือนสีส้มระบุสถานะ
2. **เมื่อพร้อมเปิดตัวสู่สาธารณะ:**
   - แอดมินเข้าหน้า `/admin.php` แล้วกดปุ่ม **"🚀 กดเปิดเว็บไซต์สู่สาธารณะ"** เพียงคลิกเดียว
   - เว็บไซต์จะเปิดให้ทุกคนเข้าชมได้ทันที โดยไม่ต้องรบกวนศูนย์พัฒนาฯ แก้ไขโค้ดหรือเปลี่ยนลิงก์อีก

### 🔐 3. ข้อมูลบัญชีผู้ดูแลระบบ (Admin Access)

- **URL เข้าสู่ระบบหลังบ้าน:** `https://[โดเมนของเว็บ]/admin.php`
- **ชื่อผู้ใช้งานเริ่มต้น:** `admin`
- **รหัสผ่านเริ่มต้น:** `epadmin2026`
- **ความปลอดภัย:**
  - เมื่อล็อกอินครั้งแรก ระบบจะแจ้งเตือนให้เปลี่ยนรหัสผ่านในแท็บ **"🔐 บัญชีและความปลอดภัย"** ทันที
  - มีระบบ Rate Limiting ป้องกันการ Brute Force (ล็อกชั่วคราว 10 นาที หากกรอกผิดเกิน 5 ครั้ง)
  - เข้ารหัสผ่านด้วย `password_hash()` มาตรฐาน BCRYPT ความปลอดภัยระดับสูงสุด

### 🚀 4. ขั้นตอนการนำโค้ดขึ้น GitHub และเซิร์ฟเวอร์โรงเรียน

#### 4.1 การนำโค้ดขึ้น GitHub ครั้งแรก (จากเครื่องผู้พัฒนา):
```bash
# 1. เข้าไปที่โฟลเดอร์โปรเจกต์
cd "e:\OneDrive\CPW\EP_WORK\00_IT WORK\01_Systems_&_Automation\Antigravity\EP Website"

# 2. เริ่มต้น Git Repository
git init

# 3. เพิ่มไฟล์ทั้งหมด (ไฟล์ขยะ/ไฟล์ชั่วคราวจะถูกกรองออกตาม .gitignore)
git add .

# 4. คอมมิตเวอร์ชัน Production
git commit -m "feat: production release with admin cockpit and visibility gateway"

# 5. เชื่อมต่อไปยัง GitHub Repository ของคุณ
git branch -M main
git remote add origin https://github.com/[YOUR-USERNAME]/[YOUR-REPOSITORY].git

# 6. ดันโค้ดขึ้น GitHub
git push -u origin main
```

#### 4.2 การติดตั้งบนเซิร์ฟเวอร์โรงเรียน (สำหรับศูนย์พัฒนาฯ หรือแอดมิน):
```bash
# Clone โปรเจกต์ลงใน Web Directory (เช่น /var/www/html/ep)
cd /var/www/html
git clone https://github.com/[YOUR-USERNAME]/[YOUR-REPOSITORY].git ep

# ตั้งค่าสิทธิ์โฟลเดอร์ข้อมูล
cd ep
chmod -R 775 data/
chown -R www-data:www-data data/
```

#### 4.3 การอัปเดตเนื้อหา/โค้ดในอนาคต:
เมื่อมีการแก้ไขโค้ดและ push ขึ้น GitHub แล้ว บนเซิร์ฟเวอร์โรงเรียนเพียงรัน:
```bash
git pull origin main
```
ข้อมูลทั้งหมดจะอัปเดตเป็นเวอร์ชันล่าสุดทันที โดยไม่ต้องส่งไฟล์ผ่านแฟลชไดรฟ์หรือรบกวนศูนย์พัฒนาฯ ทำทีละไฟล์

### 📁 5. โครงสร้างไฟล์สำคัญ

- `index.php`: หน้าแรกของเว็บไซต์
- `admin.php`: ระบบ Cockpit แผงควบคุมหลังบ้าน
- `auth.php`: โมดูลความปลอดภัย การตรวจสอบสิทธิ์ และการเข้ารหัส
- `auth_action.php`: API สำหรับเปลี่ยนรหัสผ่านและสลับโหมดปิดปรับปรุง
- `maintenance_guard.php`: ระบบดักจับการเข้าถึงและดีดไป Facebook อัตโนมัติ
- `data/maintenance_config.json`: ไฟล์ควบคุมสถานะการเปิด/ปิดเว็บและ URL ปลายทาง Facebook
- `data/db_*.json`: ฐานข้อมูลข่าวสาร, สไลด์, ครู-บุคลากร, ค่าเทอม, และผลงานรางวัล
